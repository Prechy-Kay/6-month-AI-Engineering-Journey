# DAY 3 — LEARNING TO MAKE DECISIONS WITH PYTHON 🐍
Date: August 5, 2026
Today I learned how to make Python programs make decisions using conditional logic.

## What I Learned
- Comparison operators
- if, elif, and else
- Logical operators: and, or, and not
- Nested conditions
- Boolean logic
- Testing different conditions
- Debugging

## What I Practiced
I built and tested:
- An age classification program
- A simple login checker
- A login system with multiple outcomes
- An access checker
- A Church Attendance Management System check-in scenario
I tested different inputs and learned how Python evaluates conditions from top to bottom and executes the first condition that is True.

## Debugging & Lessons
I made a few mistakes while working through the exercises, especially with the order and logic of conditions. One important lesson was that a condition can be technically valid but still produce the wrong result if the logic doesn't cover all possible situations. I also learned that and requires all conditions to be true, while or requires at least one condition to be true, and not reverses a Boolean value.

## Key Lesson
Today I learned that writing code is not just about knowing Python syntax. I need to understand the problem, think through the possible outcomes, and carefully structure my logic. The more I practice predicting what my code will do before running it, the better I'm becoming at computational thinking.
