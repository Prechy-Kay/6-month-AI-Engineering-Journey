# Day 1 — Algorithms

## What is an Algorithm?
An algorithm is a step-by-step process used to solve a problem or complete a task.

## Algorithm 1 — Church Attendance System
1. Request the person's name.
2. Check if the person is registered.
3. If the person is not registered, register the person.
4. If the person is registered, check whether they have already checked in.
5. If they have already checked in, display:
   `Already checked in`
6. If they have not checked in, display:
   `Checked in`

## Algorithm 2 — Login System
1. Request the person's username.
2. Request their password.
3. Check whether the username is correct.
4. Check whether the password is correct.
5. If the username or password is incorrect:
   - Tell the person to enter the correct credentials.
   - End the process.
6. If the username and password are correct:
   - Allow login.
   - Display `Login successful.`
