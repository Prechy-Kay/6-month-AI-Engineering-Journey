# Day 1 — Pseudocode

## Church Attendance System

START
1. Request for the person's name.
2. IF the person is not registered:
      Register the person.
3. IF the person is registered:
      Check whether the person has already checked in.
4. IF the person has checked in:
      Display "Already checked in."
5. IF the person has not checked in:
      Display "Checked in."
END

## Login System

START
1. Request for the person's username.
2. Request for their password.
3. Check whether the username is correct.
4. Check whether the password is correct.
5. IF the username and password are not correct:
      Tell the person to enter the correct credentials.
      END
6. IF the username and password are correct:
      Allow login.
      Display "Login successful."
      END
END
